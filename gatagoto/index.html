      けっか発表

      あそびかた

      🎯 目的

      サイコロをふって日本中を列車で旅しながら、駅の物件を買いあつめます。決められた年数がたったとき、総資産（所持金＋物件の値段）がいちばん多い人の勝ちです。

      🚩 目的地は「ぴったり」

      目的地の駅にぴったり止まった人だけが援助金をもらえます。通りすぎてもゴールになりません。出た目で着けるときは「✨ぴったり着ける」と出るので、分かれ道でそのルートをえらびましょう。着いたら次の目的地が決まります。

      🔀 進む方向は自由

      サイコロをふったあと、来た道にもどるのもOK。どの方向にも進めます（移動のとちゅうで、いま通った道をすぐ引き返すことはできません）。地図の金色の線が、目的地までのいちばん近い道です。

      🗺 マスの種類

      • + プラスのマス：お金がもらえます
      • − マイナスのマス：お金をはらいます
      • C カードのマス：カードを1枚もらえます（8枚まで）
      • N ナイスカードのマス：強いカードがもらえます
      • ✦ ワープマス：どこかの駅へ飛ばされます（目的地に当たればゴール！）
      • ? ？マス：宝箱・落とし穴・銀次・タヌキ・タダの物件……何が起きるかわかりません
      • 店 カード売り場：お金でカードを買えます。買うと棚に新しいカードが並びます
      • 駅 駅：物件を買えます。1つの駅の物件をぜんぶ買うと「独占」で収益が2倍！

      🃏 カード（24種類）

      1ターンに1枚使えます。急行などの移動するカードはサイコロのかわりに、スリや福袋などの移動しないカードは使ったあとにサイコロをふれます。急行・特急・新幹線・のぞみはサイコロの数がふえ、急行周遊・特急周遊は3回使えます。ちょうどは1〜6の好きな数だけ進めるので、ぴったり到着のきりふだ。まぢか・最寄り駅（目的地の手前の駅へ）・ぶっとび・場所がえ・集合で位置を変え、牛歩・いたずら・ふういん・北へ！・ぶんどり・刀狩り・スリでライバルをじゃま。おまもりは持っているだけで、いじわるカードを1回はねかえします。おはらいでタヌキを追いはらい、たからくじ・福袋・徳政令は困ったときに。千葉の先の房総半島と金沢の先の能登半島はカードマスだらけ！

      🦝 びんぼうタヌキ

      誰かが目的地に着くと、そのとき目的地からいちばん遠かった人にくっつきます。ターンの終わりに毎回、所持金の15%を持ち逃げ・カードを捨てる・カードを倍の値段で買ってくる・物件を勝手に半額で売る・お金をほかの人に配る・あなたの名前で借金してくる……と大暴れ。お金がなくても借金にされます。タヌキがついた人とすれ違う（同じマスを通る・止まる）と、タヌキは相手に乗りかえるので、わざと突っこんで なすりつけましょう。

      長くくっついているほど変身しやすくなります：大タヌキ（3ターン、物件をただで売り飛ばす・所持金の30%）、ハリケーンタヌキ（3ターン、毎回どこかへ吹き飛ばす）、ミニタヌキ（3ターン、ほぼ無害）、そしてキングタヌキ（3ターン、毎回物件2件を海に捨てて所持金の40%を奪い、カードも燃やす）。おはらいカードや2月の節分で追いはらえます。

      🌏 世界編

      日本を真ん中にした世界地図で、69の都市をめぐります。各大陸に環状ルートがあり、大西洋の路線は地図の端から反対側へつながっています。サハラ砂漠・ナラボー平原・アマゾンはカードマスだらけ。

      世界編は日本編よりダイナミックです。目的地は遠く、援助金もマスのお金も大きく、スリの銀次は多めで、タヌキはよく変身します。そして毎月、世界イベントが起きます：🏅オリンピック（開催地に止まると祝儀）、🌋火山噴火で空路が閉鎖、🏴‍☠️海賊（航路のマスに止まるとお金をうばわれる）、🏆ワールドカップで目的地が変更、🗺宝の地図（💰のマスに最初に止まった人が大金）、📉株安・📈好景気・💱為替・🛢原油高騰、🏛世界遺産登録で物件が値上がり、✈格安航空券で全員サイコロ＋1、🤝サミットで全員集合。地図の上に、いま起きていることが表示されます。

      🔥 がんばれ補正（逆転のチャンス）

      ビリの人の総資産がトップの半分以下になると「がんばれ補正」がつき、差が開くほど強くなります（🔥レベル1：半分以下、🔥🔥レベル2：3割以下、🔥🔥🔥レベル3：15%以下）。

      • 目的地に着くと援助金が2〜4倍、さらにトップの所持金の10〜25%をもらえる（下剋上）
      • 物件が20〜50%引き（総資産には元の値段で入る）、決算の収益が1.5〜3倍
      • プラスマス1.5〜3倍、マイナスマスは半分〜なし、レベル2からはサイコロ＋1個
      • いいカードが出やすい、次の目的地が近くに決まりやすい、スリの銀次は見逃し、タヌキは離れていく

      トップの人はスリの銀次に狙われやすくなります。追いつくと補正はなくなります。

      🏪 新しい物件

      決算のとき、物件がぜんぶ売れた駅（ひとりが独占している駅は除く）には新しい物件がオープンします。長い対戦でも買うものがなくなりません。

      🚢 海と空

      点線の航路に出ると列車は船に、白い点線の空路では飛行機に変わります。空路（札幌⇄東京、東京⇄那覇、福岡⇄那覇）は長い距離の近道ですが、マスは海の上。使うかどうかは作戦しだいです。

      🥷 スリの銀次・地域のできごと

      ときどきスリの銀次が現れて、所持金の一部をすっていきます（お金持ちほど狙われる）。駅に止まると、その地方ならではのできごとが起きることがあります。祭りで祝儀をもらったり、クマに追われて1回休みになったり、その地方の物件を持っている人みんなに臨時収入が入ったり。

      🌸 季節とイベント

      4月から3月まで、地図の色が季節で変わります。月のはじめに季節のイベントがあり、観光🏨・農林水産🌾・飲食🍜など物件の種類ごとに臨時収入が入ったり（GW・夏休み・収穫の秋・忘年会）、台風で修理代がかかったり、お正月にお年玉が出たり、節分でタヌキを追いはらえたりします。物件の種類は買うときのアイコンで分かります。

      🤖 コンピューターの強さ

      「よわい」は気ままに走ります。「ふつう」はぴったり着ける道を探し、「つよい」は次のターンに着きやすいマスまで考えて止まり、独占をねらい、ゴール目前の相手にいじわるカードを使ってきます。

      💴 お金・決算

      1ターンで1か月が進みます。毎年3月のおわりに決算があり、持っている物件の「収益率」ぶんのお金が入ります（種類ごとの内訳、独占した駅、順位の変動も発表されます）。所持金はマイナス（借金）にもなり、決算で10%の利息がつきます。自分の番のあいだは、「対戦状況」から物件を値段の70%で売ることもできます。

      ⏱ 説明の表示

      自分のイベントや、みんなに関係するイベント・決算は、読み終わってタップするまで待ちます。コンピューターのイベントは文章の長さに合わせて表示します。メニューの「説明の表示」で「ゆっくり／ふつう／はやい（自動）」にも変えられます。読み逃した説明は「これまでの出来事」でいつでも読み返せます。

      🔗 合言葉であそぶ

      1台目が合言葉を作って LINE などで送り、2台目が返事の合言葉を作って送り返すと、スマホどうしがじかにつながります。1台目は ひとりずつ順番に さそえます（最大4人）。ゲームは1台目が進行します。

      スマホがスリープしたり LINE を開いたりしても切れません。それでも切れてしまったら、席はそのままでコンピューターが代走します。1台目がメニューの「再接続」から新しい合言葉を作って送れば、同じ席にもどれます（ページを閉じてしまっても、タイトルから「2台目以降」で貼ればOK）。1台目は「つづきから」で再開できます。
